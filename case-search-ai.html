CASE STUDY 03 • SEARCH / APPLIED AI

Enterprise Search & AI-Assisted Workflows

Connecting user workflows, search/data platform performance, API integrations, and AI evaluation to measurable product outcomes.

The product problem

Search and authoring workflows are only useful when users can find relevant content quickly and reliably. Product quality therefore depended on both user-facing relevance and underlying indexing/retrieval performance.

Search platform ownership

  • Owned Azure Cognitive Search / Azure AI Search roadmap.
  • Translated educator and authoring workflows into search and data-platform priorities.
  • Worked across relevance, indexing performance, authoring experience, APIs, and platform scalability.
Product lensTreat performance as part of the product experience—not only an infrastructure metric. Relevance is less valuable if users wait too long, and low latency is not enough if results do not support the workflow.

Applied AI initiatives

Led initiatives spanning AI-assisted clustering/scoring workflows and an NLP-based writing assistant. My product responsibilities included user workflows, API integrations, evaluation criteria, content-safety considerations, human review, and rollout planning.

The key PM question was not “Where can we add AI?” but “Where does AI materially improve the workflow, and what quality and fallback behavior are required before users should rely on it?”

Decision framework

DimensionQuestion
User valueDoes this materially improve the educator / authoring workflow?
QualityWhat relevance, accuracy, or false-positive threshold is acceptable?
PlatformHow do latency, indexing, APIs, reliability, and scale affect the experience?
Safety / reviewWhat requires human review, fallback, or content controls?
RolloutHow should we validate quality and operational behavior before broader adoption?

What I learned

Technical metrics need a user story.Latency, relevance, accuracy, and false positives become useful product metrics only when connected to a real workflow and an explicit quality bar. That connection is what lets a PM make tradeoffs with engineering instead of optimizing isolated numbers.
